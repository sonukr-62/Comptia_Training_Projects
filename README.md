# 🤖 CompTIA DataAI Training Projects

A collection of hands-on **AI and Data Science projects** completed during my **CompTIA DataAI training**. This repository contains practical Jupyter Notebook projects covering Deep Learning, NLP, Time-Series Forecasting, and MLOps.

## 📚 Projects

### 1. 🧠 CNN Brain Tumor Classification
**File:** `CNN_Brain_Tumor_Project.ipynb`

A Deep Learning project using **Convolutional Neural Networks (CNN)** for brain tumor image classification.

**Topics:** CNN, Image Classification, TensorFlow, Keras, Model Evaluation

### 2. 🖼️ Data Augmentation
**File:** `Data_Agumentation.ipynb`

A practical project demonstrating image data augmentation techniques to increase training data diversity.

**Topics:** Image Augmentation, PIL, NumPy, Image Processing

### 3. 🌦️ LSTM Jena Climate Forecasting
**File:** `LSTM_Jena_Climate_Dataset.ipynb`

A time-series Deep Learning project using **LSTM networks** for climate/time-series analysis and forecasting.

**Topics:** LSTM, Time-Series Forecasting, Multivariate Data, Anomaly Detection

### 4. ⚙️ MLOps – Spam Message Detection
**File:** `MLOps.ipynb`

An end-to-end MLOps project covering model training, experiment tracking, model management, API deployment, and retraining.

**Topics:** Machine Learning, MLflow, Model Registry, FastAPI, Model Deployment

### 5. 💬 NLP Text Preprocessing
**File:** `NLP_DetaAI.ipynb`

A Natural Language Processing project covering common text preprocessing techniques.

**Topics:** Tokenization, Stopword Removal, Stemming, Lemmatization, NLTK
